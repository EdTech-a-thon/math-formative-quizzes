# Fact Friends

Fact Friends helps teachers organize math-fact progressions and quizzes, then
lets students practice the released activity for their class.

## Work on the app

Install dependencies with `bun install`, start PocketBase on its default local
address, and run `bun run dev`.

## Run in production

Production code, database structure and safe defaults live in this repository.
Passwords, live school data, backups and machine-specific settings do not.

See [`deploy/README.md`](deploy/README.md) for first installation, approved
updates, backups and rollback.
